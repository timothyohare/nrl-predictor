⇄ Data Flow Architecture

☰ Source-by-Source Results

Source HTTP Auth? Format Notes
nrl.com draw API 200 None JSON Cache-Control: public, max-age=5. Top-level key fixtures[]. Match ID lives inside matchCentreUrl, not at top level. Use ?competition=111&season=YYYY&round=N.
nrl.com team sheet 404 (dummy ID) None HTML/__NEXT_DATA__ Bug fixed (CURRENT_YEAR scope). 404 because draw API has no matchId/id field — match slug lives inside matchCentreUrl (e.g. raiders-v-dolphins-20260514). Lambda must extract slug from matchCentreUrl, hit /draw/nrl-premiership/{year}/{slug}, then parse __NEXT_DATA__.
nrl.com ladder 200 None JSON /ladder/data?competition=111&season=YYYY. Keys: positions[] — 17 teams, each with stats, teamNickname, movement, next. Cache-Control: public, max-age=5.
BOM REST API (daily) 200 None JSON Location search by lat/lon returns geohash. Then /forecasts/daily gives 8-day forecast: temp, rain chance, rain mm. Tested for Accor + Suncorp stadiums.
BOM REST API (hourly) 400 None — /forecasts/hourly returns 400 for both test venues. May need different geohash precision or is region-restricted. Fall back to Open-Meteo for hourly.
BOM legacy feed 404 None — reg.bom.gov.au/fwo/IDN10064/... returns 404. Dead endpoint — do not use.
Open-Meteo 200 None JSON Free, no key, global. 7-day hourly + daily. Fields: precipitation_probability, precipitation, windspeed_10m, temperature_2m. Best for non-AU venues (Las Vegas) or BOM hourly fallback.
Zero Tackle RSS 200 None RSS/XML 10 items in feed. Injury + team-list articles present. Article body is clean plain text via BeautifulSoup. Subscribe and poll every 2 h Thu–Sat.
The Roar RSS 200 None RSS/XML 6 items, multi-sport. Filter by NRL team/player keywords. Updated less frequently than Zero Tackle.
SuperCoach API Auth redirect Yes HTML All /api/v3/nrl/players endpoints return text/html (~4 KB) — login redirect. Needs Bearer token. Store in Secrets Manager: nrl-predictor/supercoach-token. Not MVP-blocking.
NRL Fantasy API Auth redirect Yes HTML fantasy.nrl.com/api/* returns text/html (~29 KB). Same auth pattern as SuperCoach. Use nrl.com/stats/data (Champion Data proxy) instead — returns real JSON with teamStats + playerStats.
nrl.com/stats/data 200 None JSON ~275 KB. Keys: teamStats, playerStats, filterSeasons. Best open alternative to SuperCoach for player data.

⚙ Recommended Scraping Strategy

Weather

  • 1
    BOM REST API — daily forecast

    Hit /locations?search={lat},{lon} for geohash, then /forecasts/daily. Free, no key, AU-hosted. Hardcode geohashes per venue as fallback.

  • 2
    Open-Meteo — hourly forecast

    BOM hourly is 400. Use Open-Meteo for kick-off-specific hourly data. Also primary for non-AU venues (Las Vegas).

  • 3
    BOM legacy feed — skip

    Dead. 404 on all tested product URLs.

Team / Draw data

  • 1
    nrl.com Draw JSON API

    Clean JSON, public cache. Fetch by round: /draw/data?competition=111&season=YYYY&round=N. Extract matchCentreUrl for team sheet lookups.

  • 2
    nrl.com Team Sheet via __NEXT_DATA__

    Fix CURRENT_YEAR bug first, then test. nrl.com is Next.js — parse the embedded JSON script tag, not CSS selectors.

Articles / Injury news

  • 1
    Zero Tackle RSS

    Best source. Poll every 2 h Thu–Sat. Filter for NRL team/player keywords. Store extracted text in S3.

  • 2
    The Roar RSS

    Secondary. Multi-sport feed — filter aggressively. Fewer NRL-specific items.

  • 3
    Haiku pre-processing step

    Don't send raw articles to the main agent. Run a cheap Haiku call to extract [{player, team, status, detail}] JSON per article. Store alongside raw text in S3.

Player prices / Fantasy signals

  • 1
    nrl.com/stats/data (Champion Data proxy)

    Open JSON, ~275 KB, teamStats + playerStats. Best free player data source.

  • 2
    SuperCoach / NRL Fantasy price delta (V1.1)

    Both require auth. Capture Bearer token via browser devtools, store in Secrets Manager. Wed night baseline → Thu night delta: >5% price drop = LIKELY_OUT signal. Not MVP-blocking.
